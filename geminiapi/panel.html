访问口令

页面通过 CPA 的 /v0/management 接口访问插件，口令只保存在这个标签页的内存里，不写 localStorage。

本地后端

后端是插件托管的本机进程：首次启动会下载 pin 版本的二进制并做 sha256 校验，校验不通过绝不启动。 它只监听 127.0.0.1；停止时按进程组回收，CPA 退出时插件会停掉它，避免遗留孤儿进程占住端口。

AI Studio 账号（Cookie 导入）

推荐流程：用无痕窗口（Firefox 或 Chrome）登录 gemini.google.com 并打开 F12 → Network → 刷新 → 点任意 gemini.google.com 请求 → Request Headers 里复制 cookie 那一行的完整值， 粘贴到下面。Cookie 只会写进本地后端自己的数据库，不写进 CPA 配置、不写进日志、也不会出现在任何响应里。 后端会定时刷新登录态，所以请不要在你平时登录着 Google 的窗口里复制，否则浏览器会被踢出登录。
